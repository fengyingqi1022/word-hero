# 单词小勇士

面向同一家庭两名孩子的本地英语单词学习网页。第一版自带两套测试词库，每个孩子有独立的词包、学习进度和答题记录。

## 现在就运行

需要 Node.js 20 或更高版本。在项目目录执行：

```powershell
npm run serve
```

然后打开 `http://localhost:4173`。首次打开会自动创建两个孩子档案，并为每人加入两个测试词包。

建议始终通过上述本地网址或正式 HTTPS 网址打开，不要直接双击 `dist/index.html` 使用 `file://` 地址。稳定的网址能让浏览器正确保存声音权限、学习数据和自动播放授权。

## 第一次启用声音

1. 在学习首页点击“开启并试听”。这是浏览器允许有声自动播放所要求的一次用户操作。
2. 打开“设置”，在“英文语音”中选择一个 `en-US` 或 `en-GB` 语音。
3. 点击“试听任意词发音”。听到完整英文句子后再开始学习。
4. Chrome 中确认“设置 → 隐私和安全 → 网站设置 → 更多内容设置 → 声音”选择了“网站可以播放声音”，并确认标签页和 Windows 音量合成器没有把 Chrome 静音。

测试词库的 16 个单词使用应用内置音频。自行导入的任意英文单词通过 Chrome、Edge 或 Safari 的系统英文语音合成。ChatGPT 内置浏览器不保证提供可用的系统语音，因此在该浏览器中只有内置音频是确定可用的。

## GitHub Pages 自动部署

项目包含 `.github/workflows/deploy-pages.yml`。代码推送到 `main` 分支后，GitHub Actions 会自动：

1. 运行全部自动化测试；
2. 构建单文件网站 `dist/index.html`；
3. 把 `dist` 发布到 GitHub Pages。

首次使用时，在 GitHub 仓库的 `Settings → Pages` 中把发布来源设为 `GitHub Actions`。本地 `dist/`、学习数据备份、私人目录和误放入项目的照片不会提交到 GitHub。

## 第一版已包含

- 两个相互隔离的孩子档案
- 两关内置测试词库，以及单文件/多文件 CSV 导入
- 同名词包导入提醒，可选择更新、作为新词包导入或跳过
- 家长可切换当前词包，并删除尚未开始的误导入词包
- 任意词包切换、更新或删除都保留已学单词的复习日期
- 新词认识卡、看中文写英文、听音写英文、英文回忆中文
- 分级提示、轻微拼写错误判定、浏览器英文发音
- 16 个测试单词的内置本地音频，可在 ChatGPT 内置浏览器中直接播放
- 两次无提示正确的掌握规则与 1/2/4/7/15/30/60 天复习阶段
- 词包通关与下一关解锁
- 每题即时保存、刷新后继续学习
- 学习报告、个人设置、完整 JSON 备份与恢复
- iPad 与电脑响应式界面

数据优先保存在 IndexedDB；若浏览器的 IndexedDB 自检失败，应用会自动降级到 localStorage。正式使用时仍建议定期导出备份。

## CSV 格式

